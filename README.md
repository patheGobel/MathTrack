# MathTrack - Plateforme de Notes

Une plateforme web pour que les élèves puissent consulter leurs notes de mathématiques.

## 🚀 Fonctionnalités

- **Authentification sécurisée** pour les élèves
- **Consultation des notes** par type d'évaluation (Tests, Devoirs, Compositions)
- **Calcul automatique des moyennes** par catégorie
- **Interface responsive** et moderne
- **Filtrage des notes** par type

## 📊 Types d'évaluation

- **Tests** : Notés sur 5 points
- **Devoirs** : Notés sur 20 points  
- **Compositions** : Notés sur 20 points
